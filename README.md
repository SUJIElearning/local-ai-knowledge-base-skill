# 知识库搭建skill

> **加载即生效，不需复制粘贴。** AI 自动成为"知识库管家"。
> 把碎片化的工作资料、学习笔记、日常知识变成 AI 可维护的"活的"知识库。

基于 Karpathy 的 LLM Knowledge Bases 模式（raw → LLM 编译 → Wiki → 输出 → 写回 → 健康检查），
为**小白用户**设计，无需写代码，只需要 Obsidian + 一个 AI 助手。

---

## ✨ 特性

- 🤖 **加载即生效** — 加载 skill 后 AI 自动成为"知识库管家"，不用复制粘贴提示词
- 🧩 **四步搭建**：收集原料 → 定规则 → AI 整理 → 建索引
- 📁 **标准目录结构**：原料/（原始资料）、知识/（整理好的卡片）、产出/（AI 成果）
- ⏰ **自动维护**：说一句"帮我整理知识库"，AI 自动执行 7 步编译流程
- 🛡️ **安全边界**：原料只读、只限仓库目录、冲突待确认
- 🌏 **中文大白话**：所有概念都用"人能听懂的话"解释
- 📦 **可复用**：作为 AI Skill 加载（DSH），或直接粘贴 SKILL.md 内容给任何 AI

## 🚀 快速开始

### 1. 安装 Obsidian

1. 打开 [obsidian.md/download](https://obsidian.md/download)
2. 下载并安装
3. 打开 Obsidian → **创建新仓库** → 取个名字（如 `MyKnowledgeBase`）
4. 记下仓库的**绝对路径**（如 `D:\我的知识库`）

### 2. 搭建目录结构

```
📁 你的知识库/
├── 📁 原料/
│   ├── 📁 网页摘录/
│   ├── 📁 灵感碎片/
│   └── 📁 工作学习笔记/
├── 📁 知识/
│   ├── 📁 人物/
│   ├── 📁 概念/
│   └── 📁 项目/
├── 📁 产出/
│   ├── 📁 辅助创作/
│   └── 📁 维护日报/
```

### 3. 放置三个核心文件

从 [`examples/`](examples/) 目录复制模板并修改：
- **规则说明书.md** → 知识库的"家规"
- **导航地图.md** → 内容目录
- **维护指南.md** → 保养手册

### 4. 加载 skill（两种方式）

**方式一：DSH 用户** → 把 `SKILL.md` 放入 `~/.dsh/skills/kb-skill/`，自动加载

**方式二：其他 AI** → 打开 `SKILL.md`，把**自动激活**部分发给 AI，然后告诉它你的知识库路径

### 5. 开始使用

扔点资料进 `原料/`，然后说一声：
> "帮我整理知识库"

AI 会自动执行 7 步维护流程，不需要你教它怎么干。

---

## 📦 作为 Skill 使用（DSH）

1. 把 `SKILL.md` 放入 `~/.dsh/skills/kb-skill/`
2. 在 DSH 中加载 skill
3. 告诉 AI 你的知识库路径，然后直接说"帮我整理知识库"

---

## ⚙️ Windows 定时任务（可选）

如果你希望电脑每天自动扫描原料区并生成日报：

1. 从 `examples/` 复制 `daily-maintenance.ps1` 到你的知识库根目录
2. 双击 `set-daily-task.bat` 注册定时任务（每天 22:00 自动运行）
3. 每天打开日报，说"帮我整理知识库"让 AI 编译
