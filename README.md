# 知识库搭建skill

> **人定义，AI 维护** — 把碎片化的工作资料、学习笔记、日常知识变成 AI 可维护的"活的"知识库。

基于 Karpathy 的 LLM Knowledge Bases 模式（raw → LLM 编译 → Wiki → 输出 → 写回 → 健康检查），
为**小白用户**设计，无需写代码，只需要 Obsidian + 一个 AI 助手。

---

## ✨ 特性

- 🧩 **四步搭建**：收集原料 → 定规则 → AI 整理 → 建索引
- 📁 **标准目录结构**：原料/（原始资料）、知识/（整理好的卡片）、产出/（AI 成果）
- 🤖 **每日自动维护**：Windows 定时任务 + AI 7 步编译流程
- 🛡️ **安全边界**：原料只读、只限仓库目录、冲突待确认
- 🌏 **中文大白话**：所有概念都翻译成"人能听懂的话"
- 📦 **可复用**：作为 AI Skill 加载，或直接粘贴提示词给任何 AI

---

## 🚀 快速开始

### 1. 安装 Obsidian

1. 打开 [obsidian.md/download](https://obsidian.md/download)
2. 下载并安装
3. 打开 Obsidian → **创建新仓库** → 取个名字（如 `MyKnowledgeBase`）
4. 记下仓库的**绝对路径**（如 `D:\我的知识库`）

### 2. 搭建目录结构

在仓库根目录下创建：

```
📁 你的知识库/
├── 📁 原料/
│   ├── 📁 网页摘录/
│   ├── 📁 灵感碎片/
│   └── 📁 工作学习笔记/
├── 📁 知识/
│   ├── 📁 人物/
│   ├── 📁 概念/
│   └── 📁 项目/
├── 📁 产出/
│   ├── 📁 辅助创作/
│   └── 📁 维护日报/
```

### 3. 放置三个核心文件

从 [`examples/`](examples/) 目录复制模板并修改：
- **规则说明书.md** → 知识库的"家规"
- **导航地图.md** → 内容目录
- **维护指南.md** → 保养手册

### 4. 告诉 AI 你的知识库

把[每日维护提示词](SKILL.md)发给你的 AI 助手（DSH / Claude / ChatGPT 等），
以后说一句"帮我整理知识库"就自动编译新资料。

---

## 📦 作为 Skill 使用（DSH 用户）

1. 把 `SKILL.md` 放入你的 `~/.dsh/skills/kb-skill/` 目录
2. 在 DSH 中通过 `skill("kb-skill")` 加载
3. 技能指令会自动注入你的系统提示词

## 📖 学习路径

| 阶段 | 内容 |
|------|------|
| 1️⃣ 认知 | 理解为什么需要 AI 知识库（人定义、AI 维护） |
| 2️⃣ 搭建 | 按四步模型（Raw→Schema→Compile→Index）创建结构 |
| 3️⃣ 维护 | 每天让 AI 整理，每周检查，每月复盘 |
| 4️⃣ 生长 | 随资料积累，知识库自动"长出"连接 |
