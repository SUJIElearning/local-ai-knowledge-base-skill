> 知识库的"家规"——告诉 AI 怎么帮你整理。

---

## 目录结构

```
{知识库根目录}/
├── 规则说明书.md      ← 家规（本文件）
├── 导航地图.md        ← 内容目录
├── 维护指南.md        ← 保养手册
├── 原料/             ← 你扔进来的原始资料（只进不出）
│   ├── 网页摘录/      ← 收藏的文章、教程
│   ├── 灵感碎片/      ← 灵光一现的想法
│   └── 工作学习笔记/  ← 工作和学习记录
├── 知识/             ← AI 整理好的知识卡片
│   ├── 人物/         ← 关于"谁"
│   ├── 概念/         ← 关于"方法/知识"
│   └── 项目/         ← 关于"项目"
└── 产出/             ← AI 干活的结果
    ├── 辅助创作/      ← 草稿和创作
    └── 维护日报/      ← 整理工作报告
```

## 命名规则

| 东西 | 怎么起名 | 例子 |
|------|---------|------|
| 一个人/一件事 | 直接叫名字 | `张三.md` |
| 一个方法/知识 | 叫它的名字 | `怎么学英语.md` |
| 一个项目 | 叫项目名 | `项目A.md` |
| 你扔的原料 | 日期+标题 | `2026-01-01_笔记.md` |

## 每张知识卡都要带"身份证"

```markdown
来源:   这条知识从哪来的
时间:   什么时候记的
标签:   关键词，方便搜索
不确定: 拿不准的地方
```

## 安全底线（AI 严格遵守）

1. 原料文件夹里的东西**绝不改动删除**，只许进
2. 只在知识库目录里干活，不碰别的地方
3. 拿不准的事**不擅自做主**，列清单等你点头
4. 重要判断永远由你拍板
